3.1 · Computer Architecture

The CPU and Microprocessors

🧠 What Does the CPU Do?

The Central Processing Unit (CPU) processes the instructions and data input into the computer to produce output. It is often called the "brain" of the computer.

  • Fetches instructions from memory
  • Decodes and executes them
  • Controls other hardware via signals

🔬 Microprocessor

A microprocessor is an integrated circuit (chip) containing the CPU on a single chip — it is small, cheap and low-power.

⚖ General-Purpose vs Specialised

General-purpose CPUSpecialised microprocessor
In PCs & laptopsEmbedded in devices
Runs many different programsPerforms one dedicated job
High performance, more powerLow cost, low power, small
e.g. Intel / AMD chipse.g. in a washing machine
A microprocessor packages the whole CPU onto one integrated circuit

Von Neumann Architecture — Core Units

🎛️ Control Unit (CU)

  • Decodes instructions so the CPU knows what to do
  • Controls the flow of data through the computer
  • Sends control signals to other components
  • Coordinates the FDE cycle

🧮 Arithmetic Logic Unit (ALU)

  • Performs arithmetic: addition, subtraction, multiplication, division
  • Performs logical operations: AND, OR, NOT
  • Performs comparisons: greater than, equal to, less than
  • Results are temporarily held in the Accumulator
CU decodes & controls; ALU calculates & compares

Von Neumann Architecture — Registers

Registers are tiny, ultra-fast memory locations inside the CPU used during processing.

RegisterStores…Mnemonic
Program Counter (PC)The address of the next instruction to be fetchedPC
Memory Address Register (MAR)The address of the memory location currently being read from or written toMAR
Memory Data Register (MDR)The data / instruction just read from or about to be written to memoryMDR
Current Instruction Register (CIR)The instruction currently being decoded and executedCIR
Accumulator (ACC)Temporarily stores results of calculations from the ALUACC
Exam tip: learn the five registers and one key phrase each — PC (next instruction), MAR (address), MDR (data), CIR (current instruction), ACC (results).

3.1 · Computer Architecture

The Fetch-Decode-Execute (FDE) Cycle

  1. Fetch: address in the PC is copied to the MAR. The instruction at that address is fetched from RAM via the data bus into the MDR. The PC is incremented by 1. The instruction in the MDR is copied to the CIR.
  2. Decode: the CU decodes the instruction in the CIR to understand what action is required.
  3. Execute: the instruction is carried out (e.g. ALU performs a calculation, data loaded into the ACC).
Exam tip: write FDE answers in the right order — Fetch first, then Decode, then Execute. Mention the registers by name for full marks.
The FDE cycle repeats for every instruction

CPU Performance Factors

⏱️ Clock Speed

Measured in Hertz (GHz) — the number of FDE cycles a CPU can perform per second.

Higher clock = faster processing

e.g. 3.5 GHz ≈ 3.5 billion cycles per second

🗃️ Cache Size

Small, ultra-fast memory inside the CPU that stores frequently used data.

Larger cache = fewer slow trips to RAM

Cache is much faster than RAM but more expensive

🔢 Number of Cores

Multiple independent processing units inside one CPU.

More cores = parallel processing

More instructions executed simultaneously

Clock speed, cache and cores all boost CPU performance

Instruction Sets & Embedded Systems

📋 Instruction Set

The list of all commands (machine code) that a specific CPU can understand and execute.

  • Every CPU has its own instruction set
  • Programs are stored as these machine-code instructions
  • Different CPUs may need different machine code for the same task
// example machine-code instructions ADD  R1, R2  ; add two values JMP  0x0040  ; jump to address

⚙️ Embedded Systems

An embedded system is a microcontroller / microprocessor built into a device to perform a dedicated function.

  • Examples: washing machines, cars (ABS), security systems, microwaves
  • Runs one fixed program — not user-programmable like a PC

⚖ Embedded vs General-Purpose

EmbeddedGeneral-purpose PC
One dedicated taskMany different tasks
Limited hardware / OSFull OS & applications
Cheap, low powerExpensive, high power

📝 Q1. Describe the role of the MAR during the fetch stage

The address of the next instruction is copied from the PC into the MAR. The MAR holds the address of the memory location being read, so the instruction at that address can be fetched into the MDR.

Any two: built into a larger device; performs a single dedicated function; has limited hardware/resources; runs a fixed program; cheap and low-power.

The Current Instruction Register (CIR).

Sensors in Computer Systems

🌡️ What Is a Sensor?

Sensors measure physical properties of the real world (temperature, light, pressure, movement…) and convert them into electrical signals.

  • Sensors are input devices
  • Their signal is analogue (continuous)
  • The CPU works with digital (0s and 1s)

🔄 The ADC

An Analogue-to-Digital Converter (ADC) converts the analogue sensor signal into digital data the CPU can process.

Sensor → ADC → CPU: analogue measurement becomes digital data
Exam tip: remember the three-step chain — sense (analogue) → convert (ADC) → process (digital).

Primary Storage — RAM vs. ROM

Primary storage is directly accessed by the CPU. The two main types are RAM and ROM.
FeatureRAMROM
Full nameRandom Access MemoryRead Only Memory
Volatile?Volatile — loses data when powered offNon-volatile — retains data
Read / write?Read and writeRead-only (can't be changed)
StoresCurrently running programs & OS dataBoot-up instructions (BIOS)

🧩 Why do we need both?

RAM gives fast, changeable working space for programs. ROM keeps the instructions the computer needs the instant it powers on — even before the OS loads.

💡 Key exam phrase

"RAM is volatile, ROM is non-volatile." Learn this exact comparison — it appears constantly.

Secondary Storage Technologies

Secondary storage is non-volatile, not directly accessed by the CPU, and used for permanent file storage (documents, photos, programs, OS).

🧲 Magnetic

Uses magnetic patterns on spinning platters.

  • Hard Disk Drives (HDD)
  • Magnetic tape (backups)
  • Cheap per GB, large capacity

💿 Optical

Uses laser light read from a spinning disc.

  • CD, DVD, Blu-ray
  • Pits & lands represent 0s & 1s
  • Portable, cheap media

⚡ Solid-State

Uses flash memory — no moving parts.

  • SSDs, SD cards, USB sticks
  • Very fast, durable, silent
  • More expensive per GB
💡
Exam Tip: the classic comparison — SSD (fast, no moving parts, expensive) vs HDD (slower, moving parts, cheap, can be physically damaged).

3.3 · Data Storage

How Storage Media Works

🧲 Magnetic (HDD)

  • Spinning magnetic platters divided into tracks and sectors
  • Read/write heads use electromagnets to change / detect magnetic states

💿 Optical (CD/DVD)

  • A laser shines on a spinning disc
  • Reads pits (indentations) and lands (flat areas) as binary 0s and 1s

⚡ Solid-State (SSD)

  • Uses NAND / NOR flash memory — no moving parts
  • Transistors act as control gates & floating gates to trap or release electrons
Exam tip: for each technology know one mechanism — HDD = magnetism, optical = laser/pits-lands, SSD = trapped electrons in flash memory.

Virtual Memory

🗄️ What Is It?

Virtual memory is a section of secondary storage (HDD / SSD) partitioned to act as RAM when physical RAM is full.

⚙️ How It Works

  1. The OS transfers inactive pages of data from RAM to virtual memory.
  2. When those pages are needed again, they are swapped back into RAM.

✅ Necessity

Prevents the computer from crashing or freezing when it runs out of RAM.

Virtual memory borrows HDD/SSD space when RAM is full
Drawback: HDD/SSD is much slower than RAM — heavy swapping makes the computer slow down.

3.3 · Quick Check

Recap — Practice Questions

Try each question, then reveal the answer.

📝 Q1. Explain how an SSD stores data

An SSD uses NAND / NOR flash memory with no moving parts. Transistors have control gates and floating gates — electrons are trapped in the floating gate to store a 1, or released to store a 0.

📝 Q2. Why is virtual memory needed, and what is a drawback?

Needed so the computer doesn't crash / freeze when RAM is full — inactive pages are swapped to HDD/SSD. Drawback: secondary storage is much slower than RAM, so heavy swapping slows the computer down.

📝 Q3. Which is volatile: RAM or ROM?

RAM is volatile (loses contents when powered off). ROM is non-volatile (keeps the boot-up BIOS instructions).

Network Interface Cards & MAC Addresses

📡 NIC

A Network Interface Card (NIC) is the hardware component required to connect a device to a network (wired or wireless).

  • Converts data into signals for the network
  • Every networked device needs one

🏷️ MAC Address

  • Media Access Control address
  • A unique physical address burned into the NIC at manufacture
  • Does not change — permanent

🔢 Structure (12 hex digits)

00:1A:2B : 3C:4D:5E

First half

Manufacturer code (OUI)

Second half

Device serial number

00 1A 2B 3C 4D 5E
manufacturer serial number
Exam tip: MAC = physical, permanent, local (finds the device on the LAN). IP = logical, can change (routes across networks).

IP Addresses — IPv4 vs. IPv6

An IP (Internet Protocol) address is a logical address allocated to a device by the network. It can be dynamic (changes) or static (stays the same).
FeatureIPv4IPv6
Bit length32-bit128-bit
Format4 denary numbers separated by dots8 groups of hex digits separated by colons
Example192.168.1.12001:0db8:85a3:0000:0000:8a2e:0370:7334
Address space~4.3 billion — running outHuge — created to provide more addresses

🌐 IPv4 example

192.168.0.1

Four parts, each 0–255 (8 bits).

🔷 IPv6 example

2001:0db8:85a3:0000:0000:8a2e:0370:7334

Eight groups of 4 hex digits.

MAC Address vs IP Address — Comparison

FeatureMAC addressIP address
TypePhysical addressLogical address
Where it comes fromBurned into the NIC at manufactureAllocated by the network
Can it change?No — permanentYes — dynamic (or static)
Bits / format48-bit, 12 hex digits32-bit (IPv4) or 128-bit (IPv6)
RoleIdentifies the device on the local networkRoutes data across networks / internet
Example00:1A:2B:3C:4D:5E192.168.1.1 / 2001:0db8:85a3::8a2e

Exam Tip: IPv4 = 32-bit, dotted decimal. IPv6 = 128-bit, colon-separated hex. "IPv6 was introduced because IPv4 ran out of addresses."

The Role of a Router

A router is a device that connects a local area network (LAN) to the internet.

🎯 Key Functions

  1. Receives data packets and reads the destination IP address.
  2. Sends / routes data packets to their correct destination.
  3. Assigns local IP addresses to devices on the network (via DHCP).

📌 Quick facts

  • Works at the network layer — uses IP addresses
  • Links your home LAN to your ISP's network
  • Also often provides Wi-Fi and a firewall
Router joins the LAN to the internet and routes packets between them

📝 Q1. State two differences between a MAC address and an IP address

Any two: MAC is physical / permanent, IP is logical / can change; MAC is burned into the NIC at manufacture, IP is allocated by the network; MAC is 48-bit hex, IP is 32-bit (IPv4) or 128-bit (IPv6); MAC works on the local network, IP works across networks.

To connect a LAN to the internet and route data packets to their correct destinations by reading the destination IP address (and to assign local IP addresses to devices).

📝 Q3. How many bits does an IPv6 address use?

128 bits — written as 8 groups of 4 hex digits separated by colons (e.g. 2001:0db8:85a3::8a2e:0370:7334).
