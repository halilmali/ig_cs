9.1

What is a Database?

A database is a structured collection of data that can be easily accessed, managed, and updated.

🗄️ Single-table (flat-file) database

All the data is stored in a single table of rows and columns — the simplest form of database, and the only form required at IGCSE.

📋 What makes it "structured"?

Data is organised into tables → records (rows) → fields (columns), so it can be searched and sorted quickly.

One table, many records (rows), each record made of fields (columns)
Example uses: school student records, a shop's product catalogue, a sports club's member list.

Fields and Records

🗂️ Field

A single column that stores a specific attribute of an entity — e.g. FirstName or DateOfBirth.

📄 Record

A single row containing all the fields for one specific entity — e.g. one student or one product.

📋 Table

A collection of related records — the whole grid of rows and columns.

One highlighted record (row) = S103 Chen Li, 9A, age 14

Worked Example: Defining a Table Structure

Scenario: a sports club needs to store member details. Define the fields, suitable data types, and validation checks:

FieldData typeValidation check
MemberIDTextFormat check (e.g. M001)
LastNameTextPresence check (must not be blank)
JoinDateDate / TimeRange check (must be a valid date)
FeePaidBooleanNone (only TRUE / FALSE)
AgeIntegerRange check (e.g. 0–120)
Why these choices?
  • MemberID → Text — codes like M001 keep leading zeros, so store as text.
  • Age → Integer — whole numbers only; no decimal ages.
  • JoinDate → Date/Time — proper dates can be compared and sorted.
  • FeePaid → Boolean — only two states: TRUE or FALSE.

Quick Check — Databases, Fields & Data Types

Q1. Explain the difference between a field and a record.

Answer: A field is a single column that stores one attribute (e.g. FirstName); a record is a single row containing all the fields for one entity (e.g. one student).

Q2. State the most suitable data type for a product price such as £4.99.

Answer: Real — prices have decimal places and need to be stored as numbers.

Q3. Suggest a validation check for a field storing a month number (1–12).

Answer: A range check — the value must be between 1 and 12 inclusive (and a type check to ensure it is an integer).

The Primary Key

A primary key is a field (or combination of fields) that uniquely identifies each record in a database table.

🔑 UNIQUE

No two records can have the same primary key value.

🚫 NOT NULL

A primary key field cannot be left blank — it must contain a value for every record.

StudentID 🔑FirstNameLastNameClass

Why it matters: the primary key lets the database find, update, and remove one specific record without affecting any others.

Identifying a Suitable Primary Key

Worked example: which field should be the primary key for this student table?

StudentIDFirstNameLastNameDateOfBirthClass
S101AishaKhan12/03/20099A
S102BenSmith25/07/20089B
S103AishaKhan12/03/20099A
S104DiyaPatel19/01/20089B
Why StudentID and not the others?
  • FirstName / LastName: two students can share a name — not unique.
  • DateOfBirth: twins could share a birthday — not unique.
  • Class: many students are in the same class — definitely not unique.
  • StudentID: every student is given a different ID — unique for every record ✓
💡Exam Tip: if an exam question asks you to choose a primary key, look for a field that is guaranteed to be unique for every single record, such as an ID number or code.

9.4

Introduction to SQL

Structured Query Language (SQL) is the standard programming language used to manage and query data in relational databases.

🗣️ What SQL does

Retrieves specific data from tables, filters it, sorts it, and performs calculations (totals and counts).

📏 IGCSE scope

At IGCSE, SQL is limited to querying data from a single table — no multi-table joins.

Worked example — the very first query
-- Show every field of every record in the Students table SELECT * FROM Students;

* means "all fields". The semicolon ; marks the end of the query.

Convention: SQL keywords are written in UPPERCASE — SELECT, FROM, WHERE…
9.4 · Structured Query Language12 / 20
9.4

SQL Syntax: SELECT and FROM

🔍 SELECT

Specifies the fields (columns) to display in the output. Use * to select all fields.

📦 FROM

Specifies the table to query.

Worked examples
-- Show FirstName and LastName for every student SELECT FirstName, LastName FROM Students;
-- Show ALL fields for every student SELECT * FROM Students;
SELECT picks the columns, FROM names the table

9.4

SQL Syntax: WHERE

WHERE filters rows — only records that match the condition are shown.

Worked examples on the Students table
-- Students in class 9A only SELECT FirstName, LastName FROM Students WHERE Class = '9A';
-- Students aged 14 or over SELECT * FROM Students WHERE Age >= 14;
OperatorMeaningExample
=Equal toClass = '9A'
<>Not equal toClass <> '9B'
< > <= >=Less than / greater than / or equalAge >= 14
Note: text values in conditions are written inside single quotes — '9A'. Numbers are written without quotes.

9.4

SQL Syntax: ORDER BY

ORDER BY sorts the output by a field — ascending (ASC, A→Z / low→high, the default) or descending (DESC, Z→A / high→low).

Worked examples
-- All students sorted by surname, A to Z SELECT FirstName, LastName FROM Students ORDER BY LastName ASC;
-- All students sorted by age, oldest first SELECT * FROM Students ORDER BY Age DESC;
Exam Tip: ORDER BY is written after WHERE (if both are used): SELECT ... FROM ... WHERE ... ORDER BY ...
9.4 · Structured Query Language15 / 20
9.4

SQL Calculations: SUM and COUNT

➕ SUM(field)

Adds up all the values in a numeric field.

🔢 COUNT(*)

Counts how many records (rows) match.

Worked examples
-- Total age of all students SELECT SUM(Age) FROM Students;
-- How many students are in the table? SELECT COUNT(*) FROM Students;
-- How many students are aged 14 or over? SELECT COUNT(*) FROM Students WHERE Age >= 14;
COUNT(*) counts rows; SUM works on one numeric field at a time and returns a single number.
9.4 · Structured Query Language16 / 20
9.4

SQL Logic: AND and OR

✅ AND

Both conditions must be true.

🔀 OR

At least one condition must be true.

Worked examples
-- Students who are BOTH in 9A AND aged 14 or over SELECT FirstName, LastName FROM Students WHERE Class = '9A' AND Age >= 14;
-- Students who are in 9A OR in 9B (i.e. everyone in both classes) SELECT * FROM Students WHERE Class = '9A' OR Class = '9B';

Quick Check — SQL

Q4. Write an SQL query to show the FirstName and LastName of all students in the Students table.

Answer:
SELECT FirstName, LastName FROM Students;

Q5. Write an SQL query to show all fields of students in class '9B', sorted by Age from highest to lowest.

Answer:
SELECT * FROM Students WHERE Class = '9B' ORDER BY Age DESC;

Q6. What does this query return?

SELECT COUNT(*) FROM Students;

Answer: A single number: the total number of records (rows) in the Students table.
