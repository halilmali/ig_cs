The Three Core Components

An automated system uses the input-process-output model:

Input (sense) → Process (decide) → Output (act).
📝 Exam Tip: Always describe the full cycle: sensor detects → microprocessor compares/decides → actuator acts. Marks are lost for skipping a stage.

6.1 · Automated Systems

How Collaboration Works — Automatic Streetlight

Worked example

💡 A light-sensitive streetlight

A continuous loop: sense → compare → act → repeat.
  1. A light sensor continuously monitors the level of light in the environment.
  2. The sensor sends this data to the microprocessor.
  3. The microprocessor compares the reading to a pre-set threshold stored in its memory.
  4. If the light level is below the threshold (it is dark), it sends a signal to the actuator.
  5. The actuator switches on the light (e.g. via a relay or motor).
  6. This cycle repeats continuously as light levels change.

6.1 · Automated Systems

Advantages of Automated Systems

  • Increased speed and productivity — tasks are completed faster than by a human worker.
  • Improved accuracy and consistency — fewer human errors; the same action is repeated identically.
  • Can operate continuously — 24/7 without breaks, rest, or fatigue.
  • Improved safety — can work in dangerous environments (e.g. extreme heat, toxic fumes).
  • Reduced long-term staffing costs — fewer workers needed once the system is installed.
Running thread — factory line

A factory inspection line runs all night without staff, checks every product to the same standard, and never misses a shift — boosting output while cutting wage bills.

Link to robots: these same advantages reappear in Section 6.2 — automation is automation, whatever the machine is called.

6.1 · Automated Systems

Disadvantages of Automated Systems

  • High initial setup / installation cost — sensors, processors, actuators and wiring are expensive.
  • Requires specialist skills to maintain and repair the system.
  • Can lead to job losses for human workers replaced by machines.
  • Less flexible / adaptable than a human when faced with an unusual situation.
  • System failure can halt an entire process — a single point of failure.
Running thread — factory line

The same line costs thousands to install, needs specialist engineers when it breaks, and if the conveyor sensor fails the whole production line stops.

Exam Focus: Evaluating a Scenario

Questions often ask you to "describe the advantages and disadvantages" for a given scenario — e.g. a hospital, a farm, or a factory.

✅ Do this

  • Link every point to the context. For a hospital: discuss patient safety, accuracy, and cost of care — not generic points.
  • State the sensor → microprocessor → actuator cycle for that specific setting.
  • Balance your answer: give at least one advantage and one disadvantage even if only one is asked to start with.

❌ Avoid

  • Copy-paste answers — generic points such as "it is fast" earn few marks if not applied to the scenario.
  • Forgetting the context-specific detail that separates top-band answers.
  • Listing robotics or AI points — this section is about automated systems only.
Model answer — hospital drug-dispensing system

Advantage: an automated dispenser measures exact doses, reducing human error that could endanger patients. Disadvantage: the equipment and staff training are costly, and a system fault could delay critical medication until repaired.

6.1 · Recap Quiz

Quick Check — Automated Systems

Q1. Describe how a sensor, microprocessor, and actuator work together in an automatic greenhouse watering system.

A soil moisture sensor detects the soil is dry and sends the reading to the microprocessor. The microprocessor compares it to a pre-set threshold and, if it is too dry, sends a signal to the actuator, which opens the valve or switches on the sprinklers. The cycle repeats.

Q2. State two disadvantages of using an automated system in a factory.

Any two: high initial setup/installation cost; requires specialist skills to maintain; can cause job losses; less flexible than a human in unusual situations; a system failure can halt the whole process.

Q3. A streetlight uses a light sensor. State what the microprocessor does when the light level drops below the threshold value.

The microprocessor sends a signal to the actuator telling it to switch the light on.

What is Robotics?

Robotics is a branch of computer science that incorporates the design, construction, and operation of robots.

🏭 Factory equipment

Industrial robotic arms that weld, paint, and assemble cars on a production line.

🏠 Domestic robots

Robot vacuum cleaners that map a room and clean it automatically.

🛸 Drones

Unmanned aircraft used for delivery, filming, and surveying.

🔬 And many more

Medical assistants, bomb-disposal units, and exploration rovers are all robots.

Not every machine is a robot: a robot is programmable and can carry out tasks automatically — a washing machine with a fixed program is usually treated as an automated system rather than a robot.

Advantages of Using Robots

  • Can work continuously without tiring — increasing overall output.
  • Perform repetitive tasks with high precision and consistency.
  • Can operate in hazardous environments unsafe for humans (e.g. bomb disposal, deep sea).
  • Increased efficiency and productivity over time, once installed.

A surgical robot holds a steady, precise instrument for hours without shaking, lets surgeons work through tiny incisions, and never tires — improving patient outcomes.

Q4. State the three characteristics of a robot.

1) A mechanical structure / framework (physical body). 2) Electrical components — sensors, a microprocessor, and actuators. 3) It is programmable, so it can be reprogrammed to do different tasks.

6.3 · Artificial Intelligence

What is Artificial Intelligence?

Artificial Intelligence (AI) is a branch of computer science dealing with the simulation of intelligent behaviours by computers.

🧠 Expert systems

Programs that use a knowledge base and rules to solve problems like a human expert (e.g. medical diagnosis).

📈 Machine learning

Programs that learn and adapt automatically from data, improving without being reprogrammed (e.g. image recognition).

Syllabus note: for this course, AI is only the two areas above — you do not need to study other forms of AI.

6.3 · Artificial Intelligence

Expert Systems: Overview

An expert system is an AI program that uses a database of knowledge and rules to solve problems in a specific field, simulating the decision-making of a human expert.

🩺 Medical diagnosis

Symptoms are entered, and the system suggests a likely condition — like a specialist doctor.

🐛 Fault finding

Diagnosing why a machine or circuit has failed based on observed symptoms.

Key phrase: the expert system imitates a human expert — it does not "think" the way a human does, it follows stored knowledge and rules.
6.3 · Artificial Intelligence21 / 27
6.3 · Artificial Intelligence

The Four Components of an Expert System

User → Interface → Inference Engine → Output, drawing on the Knowledge Base and Rule Base.
ComponentPurpose
Knowledge baseStores all the facts and data about a specific subject area.
Rule baseStores the set of rules (usually IF-THEN logic) used to reason with the facts.
Inference engineCompares data input by the user against the rules and knowledge base to reach a conclusion.
InterfaceAllows the user to input data (e.g. symptoms) and receive the output (e.g. a diagnosis).
📝 Exam Tip: A classic example is a medical diagnosis expert system: symptoms are entered via the interface, the inference engine matches them to rules, and a diagnosis is produced using the knowledge base.

6.3 · Artificial Intelligence

Machine Learning: Overview

Machine learning is when a program has the ability to automatically adapt its own processes and/or data, improving its performance over time — without being explicitly reprogrammed by a human.

🖼 Example: image recognition

Shown thousands of labelled cat photos, the system learns the pattern and recognises new cats it has never seen.

📧 Example: spam filters

The filter improves with each message you mark, adapting to new spam without being reprogrammed.
