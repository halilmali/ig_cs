The NOT Gate

10.2

From a Problem Statement to a Circuit

  1. Identify each condition mentioned in the statement as an input.
  2. Identify the logical relationship between them (AND, OR, NOT, etc.).
  3. Draw the corresponding gates connected in the correct order.
Worked example

"An alarm should sound if the door is open AND the system is armed."

Q = Door AND Armed
Two conditions → one AND gate → output Q (alarm)
Notice: one AND gate is all this statement needs — two inputs (Door, Armed) and one output (Q).
10.2 · Building Logic Circuits12 / 23
10.2

Worked Example: Three-Gate Circuit from a Problem Statement

Statement: "A warning light switches on if the temperature sensor detects a HIGH reading (T) OR the pressure sensor detects a HIGH reading (P), but NOT if the system is in manual override mode (M)."

Q = (T OR P) AND (NOT M)
Step 1: OR the two sensors (X) · Step 2: NOT the override (Y) · Step 3: AND them together (Q)
Step-by-step: (T OR P) is done by the OR gate → X. NOT M is done by the NOT gate → Y. The AND gate combines X and Y → Q.
10.2 · Building Logic Circuits13 / 23
10.2

From a Logic Expression to a Circuit

Process: work through the expression following operator precedence — brackets first, then NOT, then AND, then OR — drawing one gate at a time.

Q = (A AND B) OR NOT C
Brackets first: A AND B (gate 1) → NOT C (gate 2) → OR the results (gate 3)
Check the number of gates: two AND/OR/NOT operations inside brackets, one NOT, one final OR = exactly the complexity of the expression. Do not simplify.

Process: identify which rows produce an output of 1, then determine what combination of gates reproduces that pattern.

10.3

Setting Up a Truth Table

A truth table lists every possible combination of binary inputs (0 or 1) and shows the resulting output for each one.

🔢 How many rows?

A table with n inputs has 2ⁿ rows. Two inputs → 4 rows; three inputs → 8 rows.

📋 Order matters

List inputs in a consistent order (counting in binary), starting at 000… and ending at 111….

ABCQ (to complete)
000
001
010
011
100
101
110
111
Reference structure: three inputs, all 8 combinations in binary-count order — 000, 001, 010, 011, 100, 101, 110, 111.

Worked Example: Completing a Truth Table from a Problem Statement

Statement: "A light turns on (Q) when the motion sensor detects movement (M) AND the room is dark (D)." The room is dark when the light sensor gives NOT Light (L).

Q = M AND (NOT L)
MLNOT LQ = M AND (NOT L)
0010
0100
1011
1100
Reading the rows
  • No movement → light stays off (rows 1–2), whatever the lighting.
  • Movement and dark → light turns on (row 3).
  • Movement but the room is bright → light stays off (row 4).
Technique: turn the statement into an expression first (M AND NOT L), then build the table exactly as for an expression.
