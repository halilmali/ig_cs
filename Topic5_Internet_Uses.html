5.1 · Recap Quiz

Quick Check — The Internet & WWW

Q1. Describe the difference between the internet and the world wide web.

The internet is the physical infrastructure — a global network of interconnected computers, cables and servers. The world wide web is a service that runs on the internet — the collection of websites and web pages accessed using a browser.

Q2. Explain the role of a DNS server when a user enters a URL.

The DNS (Domain Name Server) translates the domain name (e.g. www.cie.org) into its corresponding IP address, so the browser knows which web server to contact.

Q3. State one difference between a session cookie and a persistent cookie.

A session cookie is temporary and deleted automatically when the browser is closed, while a persistent cookie remains stored on the device for a set period (or until manually deleted), even after the browser is closed.

5.2 · Digital Currency

What is Digital Currency?

A digital currency is a currency that exists only electronically — there are no physical coins or notes.

💳 How it is used

Can be used to pay for goods and services online and transferred between users digitally.

🏦 Not centralised

In most cases it is not controlled by a central bank or government — e.g. cryptocurrencies like Bitcoin.

🔐 Recorded digitally

Every transaction is recorded in a digital ledger (a blockchain) rather than in a bank's books.

🌍 Borderless

Can be sent anywhere in the world quickly, without needing a bank transfer or exchange.

Exam wording: "digital currency" = money that only exists in electronic form; "cryptocurrency" (e.g. Bitcoin) is a type of digital currency using encryption and blockchain.

Understanding Blockchain

In its basic form, a blockchain is a digital ledger — a time-stamped series of records called blocks, each holding a group of transactions. Once a block is added, it cannot be altered.

CharacteristicWhat it means
DecentralisedNot stored in one single location — copies exist across many computers on the network
TransparentThe records are visible across the network to all participants
SecureExtremely difficult to tamper with retroactively — changing one block would break the whole chain
Analogy: think of blockchain as a shared, public diary that everyone can read, where pages are locked shut as soon as they are written.
5.2 · Digital Currency15 / 27
5.2 · Digital Currency

How Blockchain Tracks Transactions

  1. A transaction is requested (e.g. a digital currency payment).
  2. The transaction is broadcast to a network of computers called nodes.
  3. The network verifies that the transaction is valid.
  4. The verified transaction is combined with others into a new block.
  5. The new block is added to the chain of previous blocks, creating a permanent, unchangeable record.
Block 2 "remembers" Block 1, Block 3 "remembers" Block 2 — altering any block breaks the chain.

5.2 · Recap Quiz

Quick Check — Digital Currency

Q4. Define what is meant by a digital currency.

A currency that exists only in electronic form — with no physical coins or notes — used to pay for goods and services online, transferred between users, and (in most cases, e.g. Bitcoin) not controlled by a central bank or government.

Q5. Describe blockchain and explain why it is difficult to alter transaction records.

Blockchain is a decentralised digital ledger made of time-stamped blocks of verified transactions linked in a chain. It is difficult to alter records because each block stores the hash of the previous block — changing one block would require changing every subsequent block on the network, which is impractical and immediately noticeable.

5.3 · Recap Quiz

Quick Check — Cyber Security

Q6. Describe how a pharming attack works.

Malicious code redirects the user from a legitimate website to a fake one without their knowledge, so that data entered on the fake site (such as login details) is stolen.

Q7. Explain how a firewall helps protect a network.

A firewall monitors and controls incoming and outgoing network traffic based on security rules, blocking unauthorised access and stopping malicious data from entering (or leaving) the network.

Q8. State two differences between a virus and a worm.

(1) A virus attaches itself to files and needs the user to open them to spread, while a worm self-replicates without attaching to a file. (2) A virus often corrupts or deletes data, while a worm mainly spreads across networks and slows systems down.
